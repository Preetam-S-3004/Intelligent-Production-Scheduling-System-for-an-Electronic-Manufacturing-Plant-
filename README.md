Intelligent Production Scheduling System for an Electronic Manufacturing Plant

Project Description:

This project is a C++ production scheduling system designed for an electronics manufacturing plant.
It helps schedule production orders, prioritize urgent work, and manage machine failures and maintenance.

Features

- Production order scheduling
- Operation dependency management
- Queue and stack implementation
- Machine and job management
- Sorting and searching
- Handling machine failures and maintenance
- Scheduling strategy comparison
- Gantt chart and performance measures

Technologies Used

- C++
- HTML

Project Files

- "short_scheduler.cpp" – C++ scheduling program
- "Intelligent Production Scheduling System.html" – HTML project file

Purpose

To improve production scheduling and help manage manufacturing operations efficiently. and reducing order delays and collisions
